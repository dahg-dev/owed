# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-09-19

### Added
- Form to add new names.
- Dynamic list of people with automatic unique IDs.
- Ability to delete contacts.

### Changed
- Improved contact form validation to reject empty or non-alphanumeric names.
- Added error feedback for invalid input and failed submissions.
- Renamed internal person references to contact terminology for consistency.

### Notes
- The app currently focuses on contact management as the foundation for future debt-tracking features.
