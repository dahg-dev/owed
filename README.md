# OWED | Debt Tracker

Application for tracking debts and contacts, built with React, TypeScript, and Vite.

## Current state

The app already includes the base contact management features:

- Add new contacts with a name
- Generate a unique ID for each person
- List all registered contacts
- Edit the name of an existing contact
- Delete contacts with a temporary undo option
- Icon set powered by `lucide-react`

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- lucide-react

## How to run

1. Install dependencies:

```bash
npm install
```

2. Start the app in development mode:

```bash
npm run dev
```

3. Build for production:

```bash
npm run build
```

## Project goal

This initial version serves as the foundation for a debt-tracking app between people. The idea is that each contact can later include movements, accumulated balance, payment management, and debt summaries.

## Roadmap

- Basic contact management
- Debt registration per person
- Overall and per-contact balance
- Payment and movement history
- Filters and search
- Local storage persistence
